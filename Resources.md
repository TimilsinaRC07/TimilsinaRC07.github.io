## Links

* **Optimization Solvers**
  * [IBM ILOG CPLEX Optimization Studio](https://ibm.com) — Academic and commercial grade solver for linear and mixed-integer programming models.
  * [Gurobi Optimizer](https://gurobi.com) — High-performance mathematical programming solver.

* **Mathematical Computing**
  * [Anaconda Python](https://anaconda.com) — Essential toolkit containing Jupyter Notebooks, NumPy, SciPy, and Pandas for data analysis.
  * [MATLAB Academy](https://mathworks.com) — Free introductory courses for numerical computing and script modeling.
